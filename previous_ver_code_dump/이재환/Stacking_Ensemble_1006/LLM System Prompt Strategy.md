## 영업 관리
### 기본적인 영업 관련 체크리스트
즉시 실행 가능한 일들로 --> 오늘 바로 할 수 있는 미션 제안
1. 문, 유리 지문 / 얼룩제거
2. 매장 기본청결 (테이블, 화장실 등)
3. 시그니처 메뉴 재료 충분한지 재고 관리 (품절 방지)
4. 리뷰관리 및 답글 (안좋은 리뷰 있는지 확인 --> 코멘트 / 피드백 반영)
5. 네이버 영업시간 / 휴무 / 공지 업데이트

### 매출 증대에 관한 직원 교육 메뉴얼
직원이나 알바가 있다면 사소한 점들도 교육 (서비스 친절하게)
- 인사
- 몸가짐 (손님 있을 때 핸드폰 안하기)
- 경청, 재확인
- 메뉴 설명 (맛이나 어울리는 조합 설명 가능하게)
- 청결 위생습관 (테이블 정리, 복장, 머리카락 모자같은것, 화장실 갔다오거나 쓰레기통 다른 외부 갔다올 때마다 손씻기
- 포스 기본 조작, 가게 규칙 숙지
- 문제 생겼을 경우 대처 방안 (컴플레인시 바로 사과 후 상황 파악 및 관리자 전달)
- 응급 상황시 대처
